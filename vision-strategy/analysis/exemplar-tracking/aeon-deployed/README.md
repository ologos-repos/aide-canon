# aeon-deployed/

Tracking the AEON-deployed exemplar — a live instance of [AEON](../../../enterprise-platforms/aeon/) at an enterprise-altitude target.

## Status

**Placeholder.** AEON-deployment is named as a future exemplar in the canon's methodology (per JD's 2026-05-22 direction). Deployment site, timeline, and scope are not yet announced.

This subfolder is established now so that:

1. The tracking convention is in place before deployment lands (no scramble at deployment time)
2. The contingency direction captured in [`../../hermetic-engagement/40-mxm-refactor/ologosai-response.md`](../../hermetic-engagement/40-mxm-refactor/ologosai-response.md) addendum has a defined target — AEON-deployed carries the AIDE-exemplar role if Hermetic's MxM-multi-agent-harness reference role doesn't materialize
3. The Vision's "at least one enterprise outside Ologos has stood up an AIDE-shaped reference" success signal has a defined tracking surface even pre-deployment

## What this exemplar will demonstrate (planned)

Once deployed, AEON-deployed tracks:

| Dimension | What it proves |
|---|---|
| **Architectural realization** | AEON's six service planes survive contact with a real enterprise environment — identity / authority / evidence / integration / capability composition / orchestration runtime all enacted |
| **Operational viability** | The four-plane AIDE architecture (control / runtime / experience / capability) is composable at enterprise scale, not just in canon prose |
| **Conformance** | The deployment conforms to OAgents behavioral envelope + OrdSA authority altitudes + (post ADR-EA-0009) the digital-thread pattern — observable end-to-end |
| **Integration** | The deployment integrates with enterprise identity / governance / monitoring infrastructure realistically |

## Vision success-signal anchor

This exemplar most directly supports the Vision success signal:

> *"At least one enterprise outside Ologos has stood up an AIDE-shaped reference — publicly described as such, with the four-plane composition recognizable in their published architecture."*

(per [`../../../vsok/vision/README.md` § What success looks like](../../../vsok/vision/README.md))

If AEON-deployed is at an Ologos-internal target, the signal is partially met (AIDE-shaped reference exists, but not "outside Ologos"); if at an external customer, the signal is fully met. The deployment context entry will note which.
