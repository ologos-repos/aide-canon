# key-results/ — Key Results (reserved)

The **Key Results** slot of [VSOK](..) within [Vision-Strategy](../..). Reserved placeholder; artifact TBD.

## What this slot holds

Measurable outcomes that anchor [Objectives](../objectives/). Each Key Result is a concrete, observable signal — pass/fail or quantified — that signals progress on its parent Objective.

Key Results are the OKR pattern's accountability layer: they make Objectives auditable without requiring deep familiarity with the corpus's argument.
